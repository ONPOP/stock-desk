# 정기 슬롯 주식 분석

## 사용자 프로필 (판단의 전제)

- 매매 패턴: **종가(마감 30분 전~마감) 매수 → 익일 시초(개장~1시간) 매도**. 초단타 아님. 오버나잇 갭 수익이 목표.
- 따라서 BUY 판단의 핵심 질문은 항상: "오늘 종가에 사면 내일 시초에 갭업으로 팔 수 있는가?"
  - 당일 수급 마감 강도, 마감 후 예정 이벤트, 시간외 동향, 관련 미국장 영향을 중심으로 평가할 것.
- SELL 판단의 핵심 질문: "보유 종목을 시초에 어떻게 처리하는가?" — 갭 시나리오별(§신호 규칙 open_sell) 대응을 제시.
- 매매는 사용자가 직접 실행한다. 이 분석은 판단 보조 자료다.

## 입력

1. `data/runs/{date}/{slot}/snapshot.json` — Python이 계산한 지표·수급·점수. **지표를 다시 계산하지 마라.** 스냅샷 값을 신뢰하고 해석만 하라.
2. `snapshot.json`의 `selected` 배열 — 분석 대상 종목 (scorer가 선정, 최대 8개). **이 목록 외 종목은 분석하지 마라.**
3. 슬롯 메타: slot_id, slot_type(quick/detail), market.

## 분석 절차 (종목당)

1. 스냅샷의 지표·국면 플래그·점수 근거를 읽는다.
2. 웹 검색으로 당일 뉴스·공시·이슈를 조사한다. **종목당 검색 최대 4회.** 우선순위: 공시/실적 > 산업 뉴스 > 수급 해석 기사. 커뮤니티/루머성 출처는 사용하지 않는다.
3. 차트 국면을 판단한다: 스냅샷의 1M/3M/6M/12M/3Y 수익률과 MA 배열로 상승장/하락장/눌림목/횡보를 서술. 룰 기반 플래그와 다르게 판단하면 그 이유를 명시.
4. 뉴스와 차트가 상충하는지 확인한다 (예: 호재인데 하락 → 이미 반영? 매도 압력?). 상충 시 confidence를 낮춘다.
5. 판단 JSON을 작성한다.

## 출력 (엄격 준수)

`data/runs/{date}/{slot}/analysis.json`에 아래 구조로만 출력한다. 다른 텍스트, 마크다운, 슬라이드 생성 금지 (quick 슬롯의 슬라이드는 Python이 렌더한다).

​```json
{
  "market_overview": {
    "summary": "지수·테마 흐름 3~5줄",
    "theme_flows": [{"theme": "...", "today_pct": 0.0, "trend": "...", "comment": "..."}],
    "macro_events": ["오늘/내일 주요 이벤트"]
  },
  "stock_cards": [ /* 01_DESIGN.md §6 종목 카드 스키마 준수 */ ],
  "usage_note": "검색 총 N회 사용"
}
​```

### 종목 카드 필수 규칙
- `bear_case` 생략 금지. 매수 논리만 있는 카드는 불량이다. "이 판단이 틀린다면 왜인가"를 반드시 2줄 서술.
- `confidence` 기준: HIGH = 지표·수급·뉴스 3요소 정합 / MID = 2요소 정합 / LOW = 상충 존재. 상충이 있는데 HIGH를 주지 마라.
- `indicators_summary`에는 반드시 **원값 병기** ("RSI 양호" 금지, "RSI 58" 형식).
- `event_flags`: event_calendar 또는 검색으로 확인된 실적발표·이벤트. 당일 밤 실적발표 종목은 signal을 BUY로 주지 마라 (AVOID + 사유).
- 확인되지 않은 정보를 사실처럼 쓰지 마라. 불확실하면 "미확인"으로 표기.

1. 지난 7일 signal_log를 조회해 신호별 적중률, 갭 분포, 패인 분석을 작성한다.

3. 결과는 상세 덱 + 텔레그램 요약.
